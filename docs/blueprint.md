# **App Name**: ZarQ

## Core Features:

- Jewellery Showcase: Display of high-resolution images of gold jewellery with zoom functionality.
- Product Filters and Views: Categorize jewellery by type (e.g., rings, necklaces, bracelets) and metal type and display it.
- Featured Items Carousel: A carousel on the homepage displaying featured jewellery pieces.
- Product Details: Display high resolution jewellery images, as well as rich detail for each individual product.
- Contact Information: Contact information including address, phone number, and a contact form for inquiries.
- Greeting message generator: AI powered tool which helps user write custom greetings for special days with jewellery suggestions

## Style Guidelines:

- Primary color: Deep gold (#D4AF37) to evoke the richness and luxury of gold.
- Background color: Dark, desaturated gray (#222222) to provide a sophisticated contrast and highlight the jewellery.
- Accent color: Antique brass (#CD7F32), a slightly desaturated shade of gold, to complement the primary color and add depth.
- Body font: 'Inter', a sans-serif font, offering a clean, modern aesthetic.
- Headline font: 'Playfair', a modern serif font, to provide a touch of elegance and luxury to headlines and titles.
- Use custom-designed icons with a gold-line art style to represent different jewellery types and website functions.
- Implement subtle animations such as a gentle zoom on images, smooth transitions between pages, and a shimmering effect on gold elements to enhance user engagement.
